# 熊伴 BearCompanion

一个原生 macOS 桌面小伙伴。当前版本 1.7.1。

## 功能

- 微信在前台时玩手机，Zotero 在前台时看书；其他应用中，获准输入监控且最近 1.5 秒有键盘活动时打字。
- 左键轻点：挠头、鼓掌或吓一跳；按住拖动：播放走路动画。
- 本地时间 22:00–07:00 自动戴睡帽，闲置时抱枕犯困；每日首次启动播放起床。
- 右键小熊或点击菜单栏“熊伴”切换状态、隐藏或退出。

## 构建与运行

需要 macOS 13 或更新版本，以及 Apple Xcode Command Line Tools。

```sh
xcode-select --install
bash build.sh
open BearCompanion.app
```

脚本按当前 Mac 的架构构建，生成本地临时签名的应用，并运行内置自检。当前开发验证环境为 Apple Silicon；Intel 未实机验证。此仓库不含已编译应用，也不适用于 Windows。

## 隐私与权限

应用不需要任何 API key、token、GPT 账号或服务器。当前源码没有联网、遥测或上传实现。
仅查询前台应用的标识和距离最近一次按键事件的时间，不读取或保存具体按键内容、聊天内容或文献内容。偏好设置在本机保存换装选项及上次起床日期。

自动打字需要在 macOS“系统设置 → 隐私与安全性 → 输入监控”中授权应用；其他模式可手动选择。系统开关和应用检测结果可能不一致，此问题尚未在所有环境解决。重新构建或替换临时签名应用可能需要重新授权。

此分享源码使用去个人化的应用标识，与早期本地版本属于不同应用。替换使用时先退出旧版本，避免同时出现两只熊；旧版本的权限和偏好不会自动迁移。
